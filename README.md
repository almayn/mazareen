# بوابة المزارعين

موقع عربي متجاوب لتسجيل المزارعين وأصحاب الآلات الزراعية. الواجهة ثابتة وتعمل على Netlify، والبيانات تحفظ في مشروع Supabase مستقل.

## إعداد قاعدة البيانات

1. افتح SQL Editor في مشروع Supabase المسمى **mazareen**.
2. انسخ محتوى `schema.sql` وشغّله مرة واحدة.
3. أنشئ مستخدم مسؤول من **Authentication → Users**.
4. أضف المستخدم إلى قائمة المسؤولين بتشغيل الاستعلام الموجود في آخر `schema.sql` بعد وضع البريد الصحيح.

يتيح إعداد RLS للزوار إرسال التسجيل فقط. القراءة والتعديل والحذف مقتصرة على حسابات المسؤولين المضافة إلى `mazareen_admins`.

## مفتاح الاتصال

في `config.js` ضع قيمة **Publishable key** (أو المفتاح القديم `anon`) من إعدادات API في Supabase مكان `ADD_SUPABASE_PUBLISHABLE_KEY`. هذا مفتاح واجهة عامة ويجب أن يبقى مقترنًا بسياسات RLS أعلاه.

**لا تضع أبدًا مفتاح Secret أو service_role في ملفات الموقع أو GitHub أو المتصفح.**

## النشر على Netlify

اربط مستودع GitHub `almayn/mazareen` بموقع Netlify جديد. إعدادات البناء:
- Build command: فارغ
- Publish directory: `.`

أي تحديث على فرع `main` سيُبنى تلقائيًا إذا كان الربط مفعّلًا.

## الصفحات

- `/index.html`: تسجيل المزارعين أو أصحاب الآلات.
- `/admin.html`: دخول المسؤول وعرض السجلات؛ لا تظهر البيانات قبل تسجيل الدخول وباجتياز سياسة RLS.


## رقم التسجيل وشاشة النجاح

بعد الحفظ تظهر شاشة تأكيد ببيانات صاحب الطلب ورقم التسجيل. الرقم يتبع سنة التسجيل، ويبدأ تسلسل السنة بالأمثلة `26110` ثم `26211` ثم `26312`، مع تسلسل مشترك للمزارعين وأصحاب الآلات. في مشروع قائم شغّل `registration-number-migration.sql` مرة واحدة في SQL Editor داخل Supabase؛ لا تعِد تشغيل `schema.sql` على قاعدة البيانات الحالية.
